CORE TRAINING

Four skills. One mission.

Use a Linux terminal in your training VM. Tick each field check as you finish it.

01

LINUX

Know where you are

The terminal is a conversation: you type a command, Linux answers. Start by identifying yourself and looking around.

trainee@linux-vm
$ whoami
trainee
$ pwd
/home/trainee
$ ls -la
.  ..  Documents  notes.txt

whoami names your user, pwd shows your location, and ls -la reveals every item—including hidden ones.

02

NETWORKS

Read the map

An IP address identifies a device. A subnet is its local neighbourhood. Find yours:

network check
$ ip -br address
lo    UNKNOWN  127.0.0.1/8
eth0  UP       192.168.50.23/24
$ ip route
default via 192.168.50.1 dev eth0
Decode it: /24 usually means nearby addresses share the first three numbers. Here, the lab neighbourhood is 192.168.50.0/24. Use the subnet shown on your VM.
03

DISCOVERY

Find listening services

nmap asks which devices and ports respond. First find live lab hosts, then inspect only the mystery host your grown-up prepared.

authorized scan
$ nmap -sn 192.168.50.0/24
# Replace this example subnet with yours.
$ nmap -sV 192.168.50.42
# Replace this IP with the new lab host you discover.

-sn discovers hosts without a port scan. -sV identifies services. Ports are doors; a web service on port 8080 is opened as http://IP:8080.

04

WEB THINKING

Test one idea at a time

Web forms send your input to a server. A secure server treats it as data. A careless one may let punctuation change the command it runs.

Inspect

In the browser, use Ctrl + U to view page source. Developers sometimes leave useful comments.

Compare

Try a normal value first. Then add a shell separator and a harmless identity command: 127.0.0.1; whoami.

Why this matters: command injection is serious. In this lab, use it only to inspect. Never try this against a site without written permission.

FINAL BRIEFING

Operation Lost Relay

A forgotten station is broadcasting somewhere on your lab network. Its web console trusts user input too much. Find the station, inspect it, and recover the operator’s access code.
